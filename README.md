# Quantitative-ESG-Research-Project

This study examines the relationship between environmental, social and governance (ESG) disclosure scores and the risk adjusted performance of 14 stocks held by the Premier ETF Sri-Kehati over 2016-2025, and explores how varying ESG weightings informs portfolio optimization. The analysis uses a tabular dataset combining ESG disclosure data from Bloomberg with historical stock prices from YahooFinance. Random Forest Regression was used to determine whether ESG disclosure scores could predict the risk-adjusted performance of individual stocks one year ahead. Monte Carlo Simulations were used to explore different ESG weightings and identify portfolios with the highest modelled risk-adjusted performance. The results showed that higher overall ESG disclosure scores were associated with stronger risk-adjusted investment performance, while the relationships between individual environmental, social, and governance scores and performance were mixed. These findings suggest that ESG disclosure scores may help inform portfolio construction, although their usefulness varies across the three pillars. The results should be interpreted within the study’s limited sample and historical period, recognising that greater disclosure does not necessarily indicate stronger sustainability performance or guarantee future investment returns and that superior investment performance may also reflect factors such as company size, sector exposure, profitability, and market conditions.

The Repository is mainly divided into two folders, which are Data and Notebook. Files outside these folders contain information on the Python version and configuration of the virtual environment used for this investigation. The Data folder contains Bloomberg ESG Disclosure Scores for the 14 SRI-Kehati constituents used in this investigation, Net Asset Values of stock market indexes used in this study, and CSV data used to transfer data between different Notebooks. The Notebook folder contains code for the data preprocessing and cleaning, Random Forest Regression of ESG metrics to future risk-adjusted performance, and Monte Carlo Simulations for testing the risk-adjusted performance of 1000 different ESG weightings. 

The Notebook is divided into three different files which are Data_Processing.ipynb , RandomForest_and_Algebraic_Regression.ipynb , and Monte_Carlo_Simulations.ipynb . Data_Processing uses Bloomberg ESG Disclosure Scores combined with YahooFinance historical closing prices to process a single, tabular dataframe to be used for the Random Forest and Monte Carlo model. RandomForest_and_Algebraic_Regression uses a combination of linear, ridge, and ols regression for a preliminary regression of ESG variables relative to future risk-adjusted returns. The file also uses Random Forest regression paired with a Random Search CV training algorithm and acts as the central predictive modelling component of this investigation. The file also produces SHAP values which will be important in determining how specific environmental, social and governance variables affect the training target. Monte_Carlo_Simulations uses Monte Carlo Simulations of 1000 different ESG weightings to deduce whether higher composite scores result in greater risk-adjusted performance for multiple hypothetical portfolios. It also does the same for individual ESG scores to infer whether specific ESG variables have divergent effects on risk-adjusted performance relative to composite scores.

The files in the repository's root directory define the Python environment used and manage the project dependencies. The .python_version file specifies the python version used in this investigation, while the pyproject.toml file specifies the project metadata, dependencies, and configuration of the project. The uv.lock file records resolved dependency installations and the disclaimer.txt file outlines relevant disclaimers to how the project's findings and source data should be used. To run the repository correctly, set up the virtual environment using the files in the root directory and run the Notebooks in order of Data_Processing -> RandomForest_and_Algebraic_Regression -> Monte_Carlo_Simulations.

It is also important to note the several limitations within this investigation. Firstly, the investigation uses only 14 out of 25 stocks from the SRI-Kehati index, with historical data ranging from 2016-2025. The lack of data points within this study therefore reduces the reliability of out of sample performance of Random Forest and reduces its generalizability across macro timeframes due to inherent risks such as overfitting. Secondly, the Random Search CV training algorithm used to optimize the Random Forest performance only used a small subset of different hyperparameters and used a small number of samples due to personal computing power deficits.

The results of this study indicate a positive relationship between composite ESG disclosure scores and future risk-adjusted investment performance, with mixed results for individual environmental, social and governance scores. Although there were no usable predictive signals from the Random Forest Regression model, the Monte Carlo Simulations indicated that portfolios with greater risk-adjusted performance tended to have higher ESG composite disclosure scores. The Monte Carlo Simulations also gave insight into how individual environmental, social and governance scores affect portfolio risk-adjusted returns. For instance, optmized portfolios tended to have higher Governance scores and lower Social scores in their respective simulations. Environmental scores on the other hand, were linked to lower volatility, but did not provide a perceptible effect on positive or negative portfolio performance. Although this suggests that ESG disclosure scores may be partially associated with risk-adjusted performance, the relationship may also be influenced by other factors such as company size, sector exposure, profitability, capital structure, and prevailing market conditions, rather than ESG disclosure scores alone.
